# Phase3: Post-MVP Experiments And Review Layers

## 目的

MVP の一本線が成立した後に、判断品質と実験速度を広げる。Rork 補助導線、Virtual Staff、より深い user state / allocation refinement はこの phase で扱う。

## 完了条件

- Rork を補助 actuator として接続できる
- Virtual Staff を advisory layer として実行できる
- user state / theme / allocation の精度を MVP より深く改善できる
